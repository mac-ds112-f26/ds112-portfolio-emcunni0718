TipHandling NA Values

There are many ways to handle missing data. The right approach depends upon your research goals. A general rule is: Only get rid of observations with missing data if they’re missing data on variables you need for the specific task at hand!

Example 1

Suppose our research focus is just on body_mass_g. Two penguins are missing this info:

Code
# NOTE the use of is.na()
penguins |>
  summarize(sum(is.na(body_mass_g)))
# A tibble: 1 × 1
  `sum(is.na(body_mass_g))`
                      <int>
1                         2

Let’s define a new dataset that removes these penguins:

Code
# NOTE the use of is.na()
penguins_w_body_mass <- penguins |>

✏️ Build daily_births

Create a new dataset named daily_births that includes the total number of births per day (across all states) and the corresponding day of the week, eg, Mon. NOTE: Name the column with total births so that it’s easier to wrangle and plot.

Code
daily_births <- Birthdays |>
  mutate(date = as.Date(date)) |>
  group_by(date) |>
  summarize(
    total = sum(births, na.rm = TRUE),
    year = first(year),
    week_day = wday(date, label = TRUE, abbr = TRUE), 
    month_day = day(date),                           
    .groups = "drop")

✏️ Plot Daily Births

Using this data, construct a plot of births over time, indicating the day of week.

Code
library(dplyr)
library(ggplot2)

 avg_births_day <- daily_births |>

  summarize(avg_births = mean(total, na.rm = TRUE), .groups = "drop")

ggplot(avg_births_day, aes(x = week_day, y = avg_births)) +

  geom_line(alpha = 0.6) +
  labs(

  ) +
  theme_minimal()

✏️ Plot Weekly Births by State

In 1988, calculate the total number of births per week in each state. Get rid of week “53”, which isn’t a complete week! Then, make a line plot of births by week for each state and comment on what you learn. For example, do you notice any seasonal trends? Are these the same in every state? Any outliers?

Code
library(dplyr)
library(ggplot2)
library(lubridate)

Birthdays_1988_weekly <- Birthdays %>%
  filter(year == 1988) %>%
  mutate(
    date = as.Date(date),
    week = isoweek(date)
  ) %>%
  filter(week != 53) %>%
  group_by(state, week) %>%
  summarize(total_births = sum(births, na.rm = TRUE), .groups = "drop")
  
  ggplot(Birthdays_1988_weekly, aes(x = week, y = total_births, group = state)) +
  geom_line(alpha = 0.5) +
  scale_x_continuous(breaks = seq(1, 52, by = 4)) +
  labs(
    title = "Total Weekly Births by State in 1988",
    x = "Week of Year",
    y = "Total Births"
  ) +
  theme_minimal()

It appears that weeks 33-41 have higher peaks which is consistent with births during late summer early fall. This matches the data from the previous graph. One state is definitely an outlier.

✏️ Compare MN & LA

Repeat the above for just Minnesota (MN) and Louisiana (LA). MN has one of the coldest climates and LA has one of the warmest. How do their seasonal trends compare? Do you think these trends are similar in other colder and warmer states? Try it!

Code
library(dplyr)
library(ggplot2)
library(lubridate)

Birthdays_MN_LA <- Birthdays %>%
  filter(year == 1988, state %in% c("MN", "LA")) %>%
  mutate(
    date = as.Date(date),
    week = isoweek(date)
  ) %>%
  filter(week != 53) %>%
  group_by(state, week) %>%
  summarize(total_births = sum(births, na.rm = TRUE), .groups = "drop")

ggplot(Birthdays_MN_LA, aes(x = week, y = total_births, color = state)) +
  geom_line(size = 1) +
  labs(
    title = "Total Weekly Births in 1988: MN vs. Louisiana LA",
    x = "Week of Year",
    y = "Total Births",
    color = "State"
  ) +
  theme_minimal()

There is overlap around week 20 which Is probably about May-ish which makes sense because both states have warmer/milder conditions during this time but there is a dramatic change during weeks 30 and 40 which is where we notice weather changes.

### ✏️ Build `daily_births`

Create a new dataset named `daily_births` that includes the total number of births per day (across all states) and the corresponding day of the week, eg, Mon. NOTE: Name the column with total births so that it's easier to wrangle and plot.

```{r}
daily_births <- Birthdays |>
  mutate(date = as.Date(date)) |>
  group_by(date) |>
  summarize(
    total = sum(births, na.rm = TRUE),
    year = first(year),
    week_day = wday(date, label = TRUE, abbr = TRUE), 
    month_day = day(date),                           
    .groups = "drop")
```

### ✏️ Plot Weekly Births by State

In 1988, calculate the total number of births per week in each state. Get rid of week "53", which isn't a complete week! Then, make a line plot of births by week for each state and comment on what you learn. For example, do you notice any seasonal trends? Are these the same in every state? Any outliers?

```{r}
library(dplyr)
library(ggplot2)
library(lubridate)

Birthdays_1988_weekly <- Birthdays %>%
  filter(year == 1988) %>%
  mutate(
    date = as.Date(date),
    week = isoweek(date)
  ) %>%
  filter(week != 53) %>%
  group_by(state, week) %>%
  summarize(total_births = sum(births, na.rm = TRUE), .groups = "drop")
  
  ggplot(Birthdays_1988_weekly, aes(x = week, y = total_births, group = state)) +
  geom_line(alpha = 0.5) +
  scale_x_continuous(breaks = seq(1, 52, by = 4)) +
  labs(
    title = "Total Weekly Births by State in 1988",
    x = "Week of Year",
    y = "Total Births"
  ) +
  theme_minimal()
```

>It appears that weeks 33-41 have higher peaks which is consistent with births during late summer early fall. This matches the data from the previous graph. One state is definitely an outlier.
